# 2026-08-22: GitHub-centred v1 and JBOM project scope

**Status:** accepted  
**Related:** ADR 0004

## Decision

Version 1 deliberately mandates the GitHub Issue/branch/worktree/PR workflow
and uses GitHub Release assets for retained evidence. This is a product scope
decision, not an assumption that PFQE, Julia or a particular GitHub repository
defines the fleet.

`Project` becomes the first-class isolation boundary for workloads and their
derived authority/evidence resources. Nodes are reusable organisation-scoped
members of the JBOM cluster. Extensibility uses reviewed, typed and versioned
provider profiles rather than generic unvalidated metadata.
